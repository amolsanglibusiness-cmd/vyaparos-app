# Expense mobile UI update
- Billed Items section is always visible, even before selecting an expense category.
- Removed Delete Items button.
- Item Name is an editable text field; typing a non-empty name automatically adds a blank row beneath it.
- Item dropdown shows saved item names and an in-dropdown + Add Item action that opens the add-item popup.
- Newly created item is added through the existing inventory persistence API.
- Expense Category is full width, with + Add Expense Category inside its dropdown.
- Reference No. appears before Payment Type; Payment Type occupies a compact half-row.
- Save button uses #87CEEB with white text.
