# VyaparOS UI Update — 2026-09-28

## Changes
- AI Commands / Assistant page: improved readability with premium dark-blue glass surfaces, visible command text, readable input/placeholder, chat bubbles, draft cards and Teach AI modal. Business logic and command parser were not changed.
- Dashboard: added dedicated Sale and Transaction action buttons matching the shared Bank/Ledger-style action language.
- Invoice list: added a dedicated Sale button next to Create Invoice; it opens the existing sale/invoice creation flow.
- Dashboard mobile date filter: all five presets (Today, Yesterday, This Week, This Month, Custom Range) are always visible in a responsive 5-column strip; the selected date range is displayed on a full-width row below.
- Existing fetchers, Supabase calls, AI command execution, accounting logic and data flows remain unchanged.
