# VyaparOS AI Assistant UI

The AI Assistant page was redesigned to follow the supplied mobile reference:
- dark navy/black mobile-first visual system
- VyaparOS gradient V branding
- animated voice/waveform hero
- greeting using the signed-in business profile first name
- language and profile controls
- quick business command cards
- live user → AI response conversation cards
- Gemini/local AI status card
- learned-command panel
- persistent bottom command composer
- mobile bottom navigation with Home, Transactions, Voice, Reports and More

Existing command execution, Gemini/local fallback, voice recognition, invoice draft/save, and learned-command memory logic are preserved. Only the AI Assistant page presentation and related response presentation were changed.
