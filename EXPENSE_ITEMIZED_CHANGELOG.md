# VyaparOS – Itemized Expense Bill

## Expense now supports
- Shop / Store name
- Multiple items in one expense bill
- Item category per line
- Quantity / weight / volume / count
- Units: नग, किलो, ग्रॅम, लिटर, मिली, बॉक्स, पॅकेट, डझन, मीटर, इतर
- Rate per unit
- Automatic line total and bill total
- Item lines saved inside the same transaction
- Offline-first Dexie persistence and existing Supabase sync queue
- Transaction search includes shop name and item names

## Supabase
Run `SUPABASE_EXPENSE_ITEMIZED_BILL_SQL.sql` once in Supabase SQL Editor.
