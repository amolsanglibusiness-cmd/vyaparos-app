# Galla Accounting Rule

- Galla and Cash in Hand are separate accounts.
- Cash page Add/Reduce remains available for both accounts.
- Galla -> Cash in Hand is a Transfer and changes both balances separately.
- A Galla expense is never blocked because of the current Galla balance.
- Every Galla expense automatically creates an equal Galla Income transaction.
- Example: Galla balance ₹0, Galla expense ₹1,000 -> Income ₹1,000 and Expense ₹1,000; Galla closing balance remains ₹0.
- Example: Galla balance ₹500, Galla expense ₹1,000 -> Income ₹1,000 and Expense ₹1,000; Galla closing balance remains ₹500.
- The automatic income is dated the same as the expense and created immediately before it so the day book shows the ₹1,000 income and ₹1,000 expense together.
